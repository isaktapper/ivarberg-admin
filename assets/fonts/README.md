# Typsnitt för Instagram-slidesen

Används av `src/lib/services/instagram-slides.ts` (Satori läser WOFF, inte WOFF2).

- **Bricolage Grotesque** 700 och 800 (rubriker), från Google Fonts
- **Inter** 400 och 500 (brödtext), från Google Fonts

Båda är licensierade under SIL Open Font License 1.1.
Filerna följer med serverless-funktionerna via `outputFileTracingIncludes` i `next.config.ts`.
